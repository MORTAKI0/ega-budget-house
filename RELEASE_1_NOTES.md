# EGA Budget House Release 1 Notes

Release 1 focuses on the core monthly budget loop:

- Add income and expense transactions.
- Save monthly starting balance and safe balance goal.
- Review selected month transactions.
- See income, expenses, current balance, safe-balance status, and category spending.

## Known Limitations

- No full offline sync.
- No bank integrations.
- No receipt scanning.
- No category editing.
- Installed PWA verification was not completed in this gate because the local in-app browser/PWA install surface was unavailable.
